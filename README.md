# Hi there, I'm Kadir Gedik! 👋

### 🚀 Full-Stack Engineer · AI-Native Systems · Autonomous Agents

I'm a third-year **Software Engineering** student at Istanbul Topkapı University, building production software end-to-end — from local development to live, deployed products. Currently shipping **CalmRoute**, a sensory-aware navigation platform for neurodivergent users across all 81 provinces of Turkey.

---

### 🛠️ What I'm Building

- 🧭 **[CalmRoute](https://calmroute.org)** — Solo founder & engineer. Custom A* routing engine in Python/Flask (3.9M nodes / 8.9M edges) with a sensory cost function, Flutter mobile client, full production infrastructure. Investor pitch June 2026, public launch July 2026.
- 🏗️ **Protocube3D** — At Hayrat Foundation: zero-infrastructure 3D printing e-commerce platform with automated geometric pricing engine (Next.js + Three.js + MongoDB).
- 🤖 **Agent Infrastructure** — At Loomon Studio: stood up the n8n + CrewAI agent stack and AI-native development practices for a 7–8 person team.
- 🛰️ **Autonomous Systems** — Contributing control systems to Teknofest-winning UAV / UGV / UUV teams at ATILAB R&D.
